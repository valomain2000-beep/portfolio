Automatisation d'un flux RSS (CERT-FR) avec JavaScript

Afin de maintenir une veille technologique active en cybersécurité, j'ai souhaité intégrer les alertes du CERT-FR directement sur mon portfolio. Voici comment j'ai contourné l'absence de backend (PHP) pour réaliser cette intégration en pur JavaScript.

1. La problématique technique

Mon portfolio est hébergé de manière 100 % statique (fichiers HTML, CSS et JS simples). Habituellement, pour lire un flux RSS (qui est au format XML), on utilise un langage côté serveur comme PHP ou Python. Si l'on essaie de lire directement le flux XML depuis le navigateur avec la fonction fetch() de JavaScript, on se heurte à une erreur de sécurité appelée CORS (Cross-Origin Resource Sharing) bloquant la requête.

2. La solution : L'API rss2json

Pour contourner ce problème de CORS et simplifier le traitement des données, j'ai utilisé une API publique nommée rss2json. Son rôle est d'agir comme un "pont" : elle va lire le fichier XML du CERT-FR sur leurs serveurs, et me le renvoyer sous la forme d'un objet JSON, un format natif et parfaitement géré par JavaScript.

3. Le code côté HTML

Dans mon fichier principal, j'ai simplement créé un conteneur vide qui va servir de réceptacle pour les cartes générées par le script.

<!-- Emplacement dans le fichier HTML -->
<div id="flux-rss" class="notes-grid">
  <p>Chargement des dernières alertes...</p>
</div>

4. Le script de récupération (Fetch API)

Voici le script développé. Il contacte l'API, récupère les 3 derniers articles, et génère dynamiquement la structure HTML pour les injecter dans la page.

// Sélection du conteneur HTML
const conteneurRss = document.getElementById('flux-rss');

// L'URL de l'API rss2json pointant vers le CERT-FR
const rssUrl = 'https://api.rss2json.com/v1/api.json?rss_url=https://www.cert.ssi.gouv.fr/feed/';

fetch(rssUrl)
  .then(response => response.json())
  .then(data => {
    // Vider le message de chargement
    conteneurRss.innerHTML = '';

    // Récupérer uniquement les 3 premiers articles
    const articles = data.items.slice(0, 3);

    articles.forEach(article => {
      // Formatage de la date en format français
      const datePropre = new Date(article.pubDate).toLocaleDateString('fr-FR');

      // Création de la carte HTML
      const carteHTML = `
        <article class="note-card">
          <div class="note-header">
            <span class="note-badge type-passive">Alerte CERT-FR</span>
            <span class="note-date">${datePropre}</span>
          </div>
          <h3 class="note-title">${article.title}</h3>
          <p class="note-excerpt">Alerte de sécurité officielle de l'ANSSI.</p>
          <a href="${article.link}" target="_blank" class="note-link">Lire l'alerte officielle →</a>
        </article>
      `;
      
      // Injection de la carte dans le DOM
      conteneurRss.innerHTML += carteHTML;
    });
  })
  .catch(error => console.error('Erreur lors du chargement du flux :', error));

Conclusion : Cette méthode m'a permis d'ajouter un tableau de bord dynamique et automatisé à mon environnement statique, tout en mettant en pratique mes compétences en scripting et en manipulation du DOM via JavaScript.
