Déploiement & Intégration Active Directory

Procédure opérationnelle pour la mise en place d'un contrôleur de domaine Windows Server et l'intégration de postes clients.

Prérequis Système

Avant de commencer : Le serveur doit disposer d'une IP fixe, d'un nom correctement défini, et le pare-feu doit autoriser le flux ICMP (Ping). Les machines clientes doivent utiliser le serveur AD comme serveur DNS principal.

Procédure d'installation (Étapes)

Étape 1 : Installation du Rôle AD DS

Sur le Windows Server, ouvrez le Gestionnaire de serveur.

  • Cliquez sur "Ajouter des rôles et des fonctionnalités".
  • Sélectionnez "Services AD DS" et validez les fonctionnalités requises.
  • Laissez l'installation se terminer.
Étape 2 : Promotion en Contrôleur de Domaine

Une fois le rôle installé, cliquez sur le drapeau d'alerte jaune en haut du gestionnaire.

  • Choisissez "Promouvoir ce serveur en contrôleur de domaine".
  • Sélectionnez "Ajouter une nouvelle forêt" et nommez-la (ex: cci.local).
  • Définissez le mot de passe de restauration DSRM.
  • Cliquez sur Installer et laissez le serveur redémarrer.
Étape 3 : Intégration d'un client Windows 10/11

Sur la machine cliente, allez dans Paramètres systèmes avancés > Nom de l'ordinateur.

  • Cliquez sur "Modifier".
  • Cochez la case "Domaine" et saisissez cci.local.
  • Entrez les identifiants Administrateur du domaine lorsqu'ils sont demandés.
  • Redémarrez le poste client pour appliquer la jonction.
