Projet Infrastructure Novembre 2025

Mise en place d'un serveur de gestion de parc (GLPI)

Installation, configuration et interfaçage d'une solution d'Asset Management et de gestion de tickets d'incidents (Helpdesk) sous un environnement GNU/Linux Debian.

1. Le contexte

L'objectif de ce projet est de déployer une infrastructure permettant d'inventorier de manière centralisée le matériel et les logiciels d'une entreprise, tout en offrant aux utilisateurs un portail (Helpdesk) pour déclarer leurs incidents informatiques.

Le socle technique retenu est Debian 12, couplé à la version 10.x de GLPI (Gestion Libre de Parc Informatique).

2. Architecture de la solution

L'installation d'un tel outil nécessite la mise en place d'une pile web classique de type LAMP (Linux, Apache, MariaDB/MySQL, PHP) :

  • Base de données : Stockage des tickets, des utilisateurs et de l'inventaire matériel.
  • Serveur Web : Hébergement du portail PHP accessible via un navigateur (interface frontend).
  • Agents de remontée : Installation de l'agent GLPI sur les postes clients pour une remontée automatique de leur configuration matérielle vers le serveur.

3. Interfaçage avec Active Directory (LDAP)

Afin de faciliter l'expérience utilisateur (Single Sign-On ou mot de passe unique) et de ne pas recréer les comptes manuellement, le serveur GLPI a été connecté à notre contrôleur de domaine Windows (Active Directory).

Configuration LDAP : Lors de la configuration, il a fallu s'assurer d'utiliser le bon attribut de synchronisation (samaccountname) pour que les identifiants de session Windows correspondent exactement à ceux importés dans l'interface web de GLPI.

4. Conclusion du déploiement

L'outil est pleinement fonctionnel. Suite à l'importation LDAP, il est désormais possible de se connecter au portail GLPI en utilisant n'importe quel compte utilisateur préalablement créé dans l'Active Directory. Les machines distantes remontent également leurs caractéristiques matérielles grâce à l'agent installé.
